# 💻 Digital Flow – SaaS Landing Page

**Digital Flow** là một **landing page hiện đại, bắt mắt và responsive** dành cho các nền tảng **SaaS (Software as a Service)**. Dự án được thiết kế với **ReactJS**, tập trung vào UI/UX mượt mà, tối ưu SEO và dễ mở rộng thành trang marketing thực tế.

---

## 🌐 Demo

🔗 [Xem demo trực tiếp tại đây](https://digital-flow-01.netlify.app)

---

## 🎯 Tính năng chính

- ✨ Giao diện hiện đại, chuyên nghiệp theo phong cách SaaS
- 🧭 Navigation rõ ràng, smooth scroll
- 📱 Responsive 100% trên mọi thiết bị
- ⚡ Tải nhanh, tối ưu hiệu năng
- 🧩 Kiến trúc component rõ ràng, dễ tái sử dụng
- 🎯 Call to action nổi bật: Đăng ký, Nhận tư vấn, Dùng thử miễn phí
- 📈 Phù hợp cho quảng cáo, landing sản phẩm hoặc demo startup

## ⚙️ Cài đặt và chạy local

```bash
# 1. Clone repo
git clone https://github.com/NaKMiers/Digital_Flow.git

# 2. Cài đặt dependencies
cd Digital_Flow
npm install

# 3. Chạy ứng dụng
npm start
```

Truy cập tại: `http://localhost:3000`
